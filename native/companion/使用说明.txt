灵犀互传 3.0 商用版 · 电脑端伴侣 使用说明
作者：军哥懂保（微信：xunijiayuan）

一、这个程序是做什么的？
浏览器受安全沙箱限制，网页本身不能被另一个网页模拟鼠标键盘。
所以「电脑被别人远程控制」需要在本机运行这个小程序：
它负责把电脑桌面画面实时发出去，并接收远端的鼠标/键盘事件，在本机真实执行。

二、安装步骤
1. 安装 Python 3.8+（安装时务必勾选 "Add Python to PATH"）
   下载：https://www.python.org/downloads/
2. 双击「启动伴侣.bat」
   首次运行会自动安装依赖（websockets / pillow / pyautogui），国内镜像加速。
3. 看到「已在房间【public】上线」即成功。

三、怎么被远程控制
1. 保持本窗口不要关闭（最小化即可）。
2. 在手机或另一台电脑打开 https://tools.ecojia.cn/lan-share-hub-pro/
3. 设备列表中会出现「你的电脑名（💻 电脑 · 电脑可被控）」
4. 点该设备的「🖱 远程控制」，即可看到桌面画面并操作鼠标键盘。

四、高级参数（可选）
在命令行设置环境变量后再启动：
  set LANHUB_ROOM=myroom     指定房间码（与网页端保持一致）
  set LANHUB_NAME=办公室电脑  自定义显示名称
  set LANHUB_FPS=10          画面帧率（默认 7，越高越流畅、越占带宽）
  set LANHUB_MAXW=1920       画面最大宽度（默认 1600）
  set LANHUB_QUALITY=65      JPEG 质量（默认 55）
  set LANHUB_WS=wss://tools.ecojia.cn/ws3   信令地址

五、常见问题
Q：网页上显示「电脑可被控」，但点远程控制没画面？
A：确认伴侣窗口仍在运行、房间码与网页一致、网络可访问 tools.ecojia.cn。

Q：能操作但鼠标偏移？
A：请保持被控电脑只接一个显示器（多屏时以主屏为准）。

Q：安全吗？
A：只有发起控制的那台设备能操作本机，其他设备会被拒绝；
   断开远程窗口或关闭伴侣窗口即立即停止。建议仅在自己信任的房间使用。
